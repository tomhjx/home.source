What this checker verifies

Checks the three required seller fields, optional certification ID, DIRECT / RESELLER relationships, comments, duplicate records, and ads.txt 1.1 declarations. Semicolon extension data is recognized but not validated. A certification ID is optional and is not required to be a specific length.

This is a syntax check, not an authorization or compliance certification. It does not verify DNS, public suffix boundaries, seller account ownership, sellers.json, certification IDs, country-code assignment, referred files, or redirect-chain compliance. HTTP metadata is checked only for fetched files. Empty files are not treated as proof that no sellers are authorized.

If fetching fails, open the file in a new tab and paste its contents here. A browser network or CORS error does not prove that ads.txt is missing.
