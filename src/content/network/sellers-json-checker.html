Scope and interpretation

Validates sellers.json 1.0 fields, seller types, confidentiality flags, duplicate seller IDs, and domain syntax. Confidential sellers may omit name and domain. Missing domains for other sellers are flagged for review because sellers without a web presence may omit them.

Joint checks compare exact, case-sensitive account IDs only for the selected advertising system. DIRECT usually corresponds to PUBLISHER or BOTH; RESELLER usually corresponds to INTERMEDIARY or BOTH. Differences are review warnings. For DIRECT records, an explicit OWNERDOMAIN is compared with the published seller domain. Other advertising systems and referred ads.txt files are not checked.

This checks supplied declarations, not real authorization or payment relationships. File provenance, public suffix boundaries, DNS, redirect chains, JSON duplicate property names, extension semantics, and the full SupplyChain object are not verified. Unlisted sellers are reported as absent from the supplied file, not globally unauthorized.
